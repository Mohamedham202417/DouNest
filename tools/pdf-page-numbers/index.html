PDF Page Numbers

Add page numbers to a PDF.

🔒 Files are processed locally when the tool supports it media

Add page numbers to a PDF.

How to use

  1. Add a PDF.
  2. Choose the number position and starting number.
  3. Run the action to download the numbered PDF.

Detailed explanation

Each page receives a page/total label.

Processing is local in your browser; encrypted PDFs may not work.

FAQ

Can numbering start at a different number?

Yes. Change the Start at value before running the action.
