List Cleaner

Trim, deduplicate and sort lists.

🔒 Files are processed locally when the tool supports it text

Trim, deduplicate and sort lists.

How to use

  1. Paste list items, one per line.
  2. Choose deduplication and the desired sorting.
  3. Copy the cleaned result.

Detailed explanation

Extra whitespace and empty lines are removed; duplicates can be ignored case-insensitively.

Keep the original order or sort alphabetically or by length.

FAQ

Will the list order change?

It is preserved by default; change the sort option to reorder the list.
