Estimate password strength without uploading it.

How to use

  1. Enter a password to test.
  2. Review the score and suggestions.
  3. Do not test a real password on an untrusted or public device.

Detailed explanation

The checker scores basic composition characteristics as a rough guide; it does not check breach databases or guarantee a real-world crack-time estimate.

It runs locally and does not store or transmit the password.

FAQ

Is the score a security guarantee?

No. Use a long unique password with a password manager and multi-factor authentication where available.
