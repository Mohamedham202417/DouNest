CSV إلى JSON

حوّل بيانات CSV إلى صيغة JSON.

🔒 تُعالج الملفات محلياً في المتصفح عندما تدعم الأداة ذلك dev

حوّل بيانات CSV إلى صيغة JSON.

طريقة الاستخدام

  1. الصق بيانات CSV في مربع الإدخال أو اسحب ملف .csv.
  2. تأكد من تحديد الفاصل الصحيح: فاصلة عادية أو فاصلة منقوطة أو Tab.
  3. فعّل خيار السطر الأول كعناوين لاستخدامها كمفاتيح.
  4. اضغط تحويل لعرض JSON في الجهة الأخرى فوراً.
  5. انسخ الناتج أو نزّله ملف .json جاهزاً للاستخدام.

شرح مفصّل

CSV لغة جداول Excel والبيانات المسطحة، وJSON لغة واجهات API والتطبيقات الحديثة — والجسر بينهما عملية يومية حقيقية: بيانات عملاء من Excel تحتاج دخول تطبيق ويب، وتقرير API يحتاج تحليل في Excel، والتحويل في الوسط دائماً.

أخطر مشكلة في التحويل هي البيانات النصية المحتوية على الفاصل نفسه: خلية تحتوي فاصلة تكسر الأعمدة إن لم تكن مقتبسة — الأداة تفهم الاقتباسات القياسية CSV وتتعامل معها بشكل صحيح.

خيار عناوين الصف الأول هو الفرق بين JSON مقروء (مفاتيح وصفية) وJSON مجهول (مصفوفات أرقام بلا معنى) — فعّله دائماً إن كان ملفك يحتوي سطر عناوين.

التحويل محلي بالكامل: بيانات عملائك ورواتبهم لا تُرفع لأي خادم — وهذا وحده سبب حاسم لتفضيل الأدوات المحلية عند التعامل مع بيانات الشركات.

الناتج القياسي مصفوفة كائنات [{...}, {...}] — الصيغة التي تتوقعها كل لغات البرمجة ومكتبات المعالجة مباشرة دون خطوات إضافية.

أسئلة شائعة

ماذا لو كانت خلاياني تحتوي فاصلة؟

الأداة تفهم الاقتباس القياسي: الخلايا المحاطة بعلامات اقتباس مزدوجة تُقرأ كخلية واحدة حتى مع فواصل داخلية.

هل يدعم الملفات العربية؟

نعم — احفظ ملف CSV بترميز UTF-8 من Excel (خيار CSV UTF-8) لضمان ظهور العربية صحيحة.

أين تتحول الخلية الفارغة؟

تصبح null في JSON — إن أردت سلسلة فارغة استخدم الخيار المناسب في الإعدادات.
