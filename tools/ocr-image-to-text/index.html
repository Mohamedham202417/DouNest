استخرج النص من الصور والمستندات الممسوحة — عربي وإنجليزي.

طريقة الاستخدام

  1. اختر صورة تحتوي نصاً (لقطة شاشة أو صورة مستند).
  2. حدد اللغة: العربية أو الإنجليزية أو معاً.
  3. اضغط «استخراج النص» وانتظر شريط التقدم.
  4. انسخ النص أو نزّله كملف txt.

شرح مفصّل

يعمل المحرك عبر Tesseract.js — نسخة المتصفح من محرك Tesseract الشهير المفتوح المصدر بدقة 100+ لغة.

يُعدّ OCR بالعربية ميزة نادرة في الأدوات المجانية؛ هنا يعمل كاملاً على جهازك بما يناسب المستندات الشخصية.

لنتائج أفضل: استخدم صوراً واضحة بإضاءة جيدة ودقة عالية، وقصّ المساحات الزائدة قبل الاستخراج.

أسئلة شائعة

هل يدعم الاستخراج النص العربي؟

نعم، اختر «العربية» أو «عربي + إنجليزي» للنصوص المختلطة — تحميل بيانات اللغة يحدث لأول مرة فقط.

أستطيع تحويل صورة إلى Word؟

استخرج النص أولاً ثم انسخه إلى أي محرر، أو استخدم أداة «CSV إلى Excel» للبيانات الجدولية.
