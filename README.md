# ToolNest — Free Browser Tools

A mobile-first, bilingual, static tools website.

## Included tools

- Image compressor
- Image format converter
- JSON formatter
- Text comparison
- Word counter
- Unit converter
- Password generator
- Color converter
- Base64 encoder/decoder
- URL encoder/decoder
- CSV/JSON converter
- JWT inspector
- Hash/checksum generator (SHA-256, MD5)
- Regex tester
- Timestamp converter
- Slug generator

## Run locally

Open `index.html` in your browser.

For best clipboard support, use localhost or HTTPS:

```bash
python3 -m http.server 8080
```
