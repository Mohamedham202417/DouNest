Sherlock — Hunt a Username Across Hundreds of Sites

A curated rare tool — full explanation, getting-started steps and hashtags.

Ethical Hacking & Security Free & open source

⚠️ These tools are intended for ethical penetration testing on systems you have explicit permission to test. Using them on systems you are not authorized to access is a crime in most countries.

DouNest does not host or interactively run any tool here — these are information pages linking to the official projects only.

What is this tool?

Sherlock is an open-source Python project that searches a single username across 400+ social networks and platforms at once, reporting where it is registered and where it is not. A classic OSINT tool used by security investigators and journalists to verify accounts tied to a digital identity.

Why we recommend it

Most people reuse the same username everywhere, which makes Sherlock a shocking window into your real digital footprint. Run it on your own name to discover how many forgotten accounts are still alive — then actually close them.

How to get started

  1. Install Python, then clone Sherlock from its official GitHub repository.
  2. Run: python sherlock <username> and watch the list of checked sites.
  3. Open each positive hit and manually confirm it is really you and not a namesake.
  4. Log forgotten accounts and decide to close or secure them.
  5. Use the results to improve privacy: different usernames for different contexts.
