How to use

  1. Click the large color swatch to open the interactive picker.
  2. Drag within the gradient area and pick the hue on the vertical strip.
  3. Or enter a HEX value directly if you know it.
  4. Read the auto-generated values in all formats: HEX, RGB and HSL.
  5. Click any format's copy button to use it in your code instantly.

Detailed explanation

A color picker is the interface tool opened dozens of times daily: a button color, a background, a shadow tone, a secondary text color — the loop repeats in every UI project, and any friction in the tool accumulates hours monthly.

The model used is the HSV/HSL familiar from design software: hue on a vertical strip, saturation and lightness in the gradient square — far easier than imagining raw RGB numbers.

Live preview on two backgrounds (light and dark) prevents the surprise of a color that looks great isolated and disappears on the actual site background.

Generating all formats at once removes the need for a separate converter: take HEX for CSS, RGB for JavaScript, HSL for shade generation — each one click to copy.

Integration with the rest of DouNest completes the loop: pick here, convert in the color converter, generate the family — all local and instant.

FAQ

Does the picker support transparency?

Use the alpha strip when shown, or get RGBA from the color converter after entering the value.

Why does the color differ between screens?

Screen calibration varies naturally — rely on official brand HEX values, not your eye.

Which format should I use in CSS?

HEX for constants, RGB for programmatic alpha, HSL for color families — all three supported.
