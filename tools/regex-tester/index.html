How to use

  1. Type your regex pattern in the top pattern field.
  2. Enable needed flags: g for global, i for case-insensitive, m for multiline.
  3. Paste test text into the large box.
  4. Watch every match highlight instantly as you type.
  5. Inspect capture groups in the side panel and refine your pattern progressively.

Detailed explanation

Regular expressions are a complete miniature language for describing text patterns: a valid email, a formatted phone number, an HTML tag, a date — all captured by one line instead of dozens of nested conditionals.

A live lab changes learning entirely: instead of writing a pattern, running a program and reading an error, you watch matches form in real time as you type — every character you add shows its effect instantly, the fastest path to understanding.

Common mistakes the lab exposes immediately: greedy patterns (+ instead of +?) swallowing too much, forgotten flags, and capture groups not capturing what you think — all visible rather than guessed.

For professionals: the lab is perfect for understanding other people's patterns — paste a complex pattern from an open-source library with test text and watch its parts work piece by piece.

A performance warning: complex patterns over huge text can freeze weak browsers — test on small samples first, then apply in your code with length bounds.

FAQ

Does the tool support JavaScript's regex flavor specifically?

Yes — the pattern runs on your browser's own RegExp engine, matching your code's behavior exactly.

How do I make a pattern non-greedy?

Add a question mark after the quantifier: .*? instead of .* — try the difference live in the lab.

What does the g flag do?

It makes the search find every match, not just the first — without g it stops at the first hit.
