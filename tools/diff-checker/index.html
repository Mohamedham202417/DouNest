Compare two texts and show differences.

How to use

  1. Paste the original into the left box and the modified into the right.
  2. Watch differences highlight instantly: green for additions, red for deletions.
  3. Enable line-by-line or character-by-character mode per required precision.
  4. Check the summary strip for addition and deletion counts.
  5. Copy the diff report or document it in your code review.

Detailed explanation

Text comparison is a hidden daily operation across tech jobs: reviewing code changes before approval, comparing two contract versions, checking what changed in a config file, verifying an edited translation — all need an eye that misses not a single line.

The comparison algorithm (LCS — longest common subsequence) is smart enough to distinguish real additions and deletions from merely moved lines — the difference between a logically readable report and meaningless noise.

Character mode is gold for precise comparisons: a single space difference in a password, or one comma in JSON — tiny details that break systems and vanish from a line-level eye.

In code reviews without Git (or with text outside repositories) this tool replaces your memory entirely: see the diff directly instead of reading 500 lines hunting for the change.

Everything is instant and local — your texts (even unpublished ones) never upload to any server, so confidential comparisons are perfectly safe.

FAQ

Does it detect moved lines?

The base algorithm shows them as delete+add; LCS keeps the reading logical despite that.

Does it support large files?

Thousands of lines run smoothly; comparing entire books may slow rendering — split if needed.

Can I compare two files directly?

Open both files and paste their contents into the two boxes — copy-paste from any text editor works.
