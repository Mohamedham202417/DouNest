Image to Base64 Converter

Convert an image to Base64 text or a Data URL in your browser. 8 MiB file limit.

How to use

  1. Choose a local image in a common format such as PNG, JPEG, or WebP.
  2. Choose raw Base64 when the destination expects encoded bytes, or a Data URL when it needs the data:image/...;base64 prefix.
  3. Convert, copy the result, and test it in the page or application that will consume it.

Detailed explanation

Base64 represents binary bytes using text characters. It does not change the image format or compress the picture; the resulting text is larger than the original file, so it may be unsuitable for large images or pages containing many embedded images.

Use raw Base64 with an API that expects only the encoded string. Use a Data URL when embedding an image in HTML, CSS, or another field that accepts a complete data URL. Its MIME type comes from the browser-provided file type.

The tool reads the file with the browser File API and does not upload it to DouNest. The 8 MiB limit helps control memory use, but the output can still occupy substantial space when copied or embedded. Avoid placing private data in a public destination.

FAQ

Does Base64 reduce image size?

No. Encoding is not compression, and the text is usually larger than the binary file. Use an image compressor if your goal is to reduce size.

What is the difference between Base64 and a Data URL?

Base64 is the encoded text alone. A Data URL adds a prefix containing the media type, such as data:image/png;base64,.
