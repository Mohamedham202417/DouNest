حوّل مصفوفات JSON إلى CSV.

طريقة الاستخدام

  1. الصق بيانات JSON (مصفوفة كائنات) في مربع الإدخال.
  2. تأكد أن البيانات مصفوفة من كائنات متشابهة البنية.
  3. فعّل خيار تضمين صف العناوين في الأعلى.
  4. اضغط تحويل لعرض CSV فوراً في الجهة الأخرى.
  5. نزّل الملف وافتحه في Excel مباشرة — أو انسخ والصق.

شرح مفصّل

الاتجاه العكسي من JSON إلى CSV هو رحلة التقرير الكلاسيكية: بيانات API خام تحتاج عرضاً لغير التقنيين، ومدير يريد Excel لا JSON، وصفحة تحليل تحتاج جدولاً — كلها تنتهي عند هذا التحويل.

أصعب تقنياً في هذا الاتجاه: الكائنات ذات المفاتيح المختلفة؛ الأداة تجمع كل المفاتيح الموجودة في كل الكائنات وتنشئ عموداً لكل مفتاح، والخلية الناقصة تصبح فارغة — سلوك منطقي يحفظ كل البيانات.

القيم المتداخلة (كائنات داخل كائنات) تُسطّح إلى تمثيل نصي أو تُتجاهل حسب الإعدادات — CSV بطبيعته جدول مسطح لا يفهم التداخل، والأسلوب النقي للحصول على CSV نظيف هو تسطيح بياناتك أولاً.

الملفات العربية تحتاج ترميز UTF-8 مع BOM لتفتح صحيحة في Excel مباشرة — الأداة تولّد الترميز الصحيح تلقائياً لتفادي مفارقة الحروف المشوهة الشهيرة.

الناتج ملف CSV قياسي مقتبس حسب الحاجة — يفتح في Excel وGoogle Sheets وLibreOffice وكل أدوات الجداول بدون أي معالجة يدوية.

أسئلة شائعة

ماذا لو اختلفت مفاتيح الكائنات؟

تُجمع كل المفاتيح كأعمدة، والخلايا الناقصة تُترك فارغة — لا تُفقد أي بيانات.

كيف تظهر العربية في Excel؟

الملف النازل مُرمّز UTF-8 مع BOM فيفتح صحيحاً مباشرة دون استيراد يدوي.

هل يدعم الكائنات المتداخلة؟

تُسطّح إلى نص أو تُتجاهل حسب الإعدادات — للتقارير النظيفة سطّح بياناتك أولاً.
