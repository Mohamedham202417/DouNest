اعرض بيانات EXIF في صور JPEG، مثل طراز الكاميرا وتاريخ الالتقاط وبعض معلومات الموقع، محلياً.

طريقة الاستخدام

  1. اختر صورة JPEG.
  2. اضغط عرض بيانات EXIF.
  3. انسخ القيم التي تحتاجها؛ لا ترسل الصورة إلى أي خادم.

شرح مفصّل

يعرض القارئ مجموعة من حقول EXIF الشائعة مثل طراز الكاميرا وتاريخ الالتقاط وبعض معلومات GPS.

يعمل هذا القارئ مع JPEG فقط ولا يضمن عرض كل الوسوم أو صيغ الصور الأخرى.

افحص بيانات الموقع قبل مشاركة الصور إذا كانت الخصوصية مهمة لك.

أسئلة شائعة

لماذا لا تظهر بيانات الموقع؟

قد لا تحتوي الصورة على GPS، أو قد تكون البيانات أزيلت عند تصديرها أو مشاركتها.
