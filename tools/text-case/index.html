How to use

  1. Paste the text whose casing you want to change into the input.
  2. Pick UPPERCASE for strong headings or lowercase for full demotion.
  3. Or use Title Case to capitalize every word — ideal for headlines.
  4. Or Sentence case to capitalize only each sentence's first letter.
  5. Grab camelCase or snake_case for code variables, then copy the output.

Detailed explanation

Changing text case looks trivial until you face 500 rows of data written in ALL CAPS by a legacy system, or a headline delivered in all lowercase — manual fixing is practically impossible, and the tool does it in one click.

Code formats carry their own rules: camelCase for JavaScript variables, snake_case in Python and SQL, kebab-case for filenames and URL slugs — picking the wrong one breaks builds or creates silent bugs.

Smart conversions go beyond letter flipping: Sentence case must understand sentence boundaries, and Title Case knows the excluded small words (of, the, in...) per style rules.

Content writing benefits equally: standard headline conventions in articles and docs follow specific casing rules, and hand-fixing a long title is an error waiting to happen.

For batch processing: paste a whole list (usernames, links, SKUs) and convert everything at once instead of editing line by line.

FAQ

Are Arabic letters respected in conversion?

Arabic has no upper/lower case so it stays untouched; only mixed-in Latin letters are affected.

What is the difference between Title Case and Sentence case?

Title capitalizes every important word in a headline; Sentence capitalizes only each sentence's first letter.

Does it handle symbols and numbers?

Yes — they pass through untouched; conversion affects letters only.
