مركز النصوص — تنظيف وتحويل وتحليل

نظّم النصوص وحوّل Markdown إلى HTML وأنشئ Slug واحسب الكلمات — محلياً.

افتح الصفحة في متصفحك لاستخدام مساحة العمل التفاعلية.

مجموعة أدوات سريعة للكتابة والنصوص: عدّ الكلمات والأحرف، تنظيف القوائم، إنشاء Slug، أو تحويل Markdown إلى HTML. الصق النص، اختر المهمة، وانسخ النتيجة أو نزّلها.

طريقة العمل

  1. الصق النص أو حمّل ملف TXT أو Markdown مدعوماً.
  2. اختر الإجراء واضبط خياراته، مثل إزالة التكرار أو الفاصل في Slug.
  3. نفّذ العملية، ثم انسخ النتيجة أو نزّلها وراجعها قبل نشرها.

أدوات النصوص المتاحة

يتضمن المركز إحصاءات النص، وتحويل Markdown إلى HTML، وتنظيف القوائم من الأسطر الفارغة أو المكررة مع خيارات للترتيب، وتوليد Slug مع إمكانية إبقاء الحروف العربية. يمكن فتح أدوات عدّ الكلمات وتغيير حالة الأحرف والنص التجريبي من البطاقات المرتبطة.

نظّف البيانات قبل نشرها

قد يغيّر التنظيف الترتيب أو يحذف عناصر تراها مكررة؛ اختر إعدادات إزالة التكرار والترتيب بعناية. تحويل Markdown إلى HTML ينتج محتوى منظماً، لكن افحص الرابط والوسوم والاقتباسات في التطبيق الذي سيعرض الملف.

الخصوصية

مدخلات النص تعالج داخل المتصفح ولا تُرسل إلى خادم DouNest. لا تستخدم متصفحاً مشتركاً لإدخال أسرار أو بيانات حساسة، وامسح مربع الإدخال عند الانتهاء.

أسئلة شائعة

هل يُرسل النص إلى خادم؟

لا، عمليات هذا المركز تعالج النص في المتصفح ولا ترسله إلى خادم DouNest.

ما هو Slug؟

هو الجزء المقروء من رابط الصفحة؛ استخدم كلمات موجزة وافصلها بشرطة، ثم راجع توافقها مع قواعد موقعك.

هل يمكن إزالة العناصر المكررة من قائمة؟

نعم، اختر تنظيف القوائم وفعّل إزالة التكرار؛ يمكنك أيضاً تحديد حساسية حالة الأحرف وطريقة الترتيب.

هل يحوّل Markdown إلى HTML آمن؟

ينشئ المركز HTML من Markdown؛ افحص الناتج قبل إدراجه في موقع، وطبّق سياسات التعقيم الخاصة بمنصتك عند عرض مدخلات غير موثوقة.
