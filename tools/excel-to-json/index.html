حوّل أوراق Excel إلى JSON جاهز للمبرمجين وواجهات API.

طريقة الاستخدام

  1. اختر ملف Excel.
  2. اختر الورقة ووضع الإخراج: مصفوفة كائنات (الصف الأول مفاتيح) أو مصفوفة صفوف.
  3. اضغط «تحويل».
  4. انسخ JSON أو نزّله مباشرة.

شرح مفصّل

وضع «مصفوفة كائنات» ينتج JSON بمعرّفات واضحة من صف العناوين — الأنسب لاستيراد البيانات في التطبيقات وقواعد البيانات.

تُحوَّل القيم الرقمية والتواريخ بأنواعها الصحيحة تلقائياً حيث أمكن.

أداة أساسية للمطورين والباحثين الذين يبدأون من جداول Excel وينتهون إلى واجهات برمجية.

أسئلة شائعة

ما الفرق بين وضعي الإخراج؟

«كائنات» يفسر الصف الأول كمفاتيح وينتج [{عمود: قيمة}] — «صفوف» ينتج [[صف1],[صف2]] كما هي.
