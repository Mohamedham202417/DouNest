How to use the PDF hub

  1. Choose an operation or open its standalone tool for a direct task page.
  2. Add one or more files as required. Arrange merge inputs first; operation-specific settings appear after selection.
  3. Run the task, then verify page order, links, text, and visual quality in the output.

What can you do here?

The hub includes adjustable image-based compression, merge, split-to-pages, rotation, PDF-page-to-image export, text extraction, and image-to-PDF, plus separate tools for organizing pages, adding watermarks, and numbering pages.

Important compression and conversion limits

The current compression method redraws each page as a JPEG image. Text may no longer be searchable or selectable, and links or interactive elements may be lost. Compression is not guaranteed to shrink every file: text-heavy PDFs can grow when rasterized. Test settings on a copy.

Privacy and compatibility

Selected files are not sent to a DouNest server. Some processing libraries are loaded on first use from a content-delivery network, so an initial internet connection is required. Encrypted or damaged PDFs may fail.

Frequently asked questions

Can I compress a PDF without losing searchable text?

The current compressor rasterizes pages. Do not use it when searchable or selectable text must be preserved; keep the original and inspect the output.

How do I merge PDFs in the right order?

Add files in the desired order and use the file-order arrows, when shown, before running Merge. Review the resulting document.

Can this extract text from scanned PDFs?

Text extraction works when the PDF contains a text layer. Scanned image pages need OCR; exporting to TXT or Word does not perform OCR.

Are my documents uploaded?

Selected files are processed in your browser and are not sent to a DouNest server. Avoid sensitive files on shared devices and clear the file list when finished.

Why did the PDF get larger?

Many pages rendered at high resolution can increase size. Try lower resolution or quality on a copy and compare readability and file size.
