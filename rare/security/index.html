🛡️ Ethical Hacking & Security

The most famous open-source security tools — information pages only, with a mandatory legal warning.

Find comprehensive information pages for the world's most famous penetration-testing tools: what they do, why they are famous, and how to start with them legally inside your own lab. These are information pages only — no interactive tools here — and every page carries a clear legal warning because using these tools against systems you are not authorized to test is a crime in most countries.

⚠️ These tools are intended for ethical penetration testing on systems you have explicit permission to test. Using them on systems you are not authorized to access is a crime in most countries.

DouNest does not host or interactively run any tool here — these are information pages linking to the official projects only.
