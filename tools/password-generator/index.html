How to use

  1. Set the password length — at least 16 characters for important accounts.
  2. Toggle character groups: uppercase, lowercase, digits and symbols.
  3. Use the exclusion option if a system rejects certain symbols.
  4. Press Generate and save the result immediately in a password manager.
  5. Generate a different password per account — regeneration is unlimited.

Detailed explanation

Password strength is measured by true randomness, not apparent complexity; P@ssw0rd looks fancy but sits at the top of every attack dictionary, while a random 16-character string would take millions of years to crack with current computing power.

The tool uses your browser's cryptographic random generator (crypto.getRandomValues) — the same entropy grade used for HTTPS key generation, not the ordinary pseudo-random generators found on many sites.

Length is king: doubling length squares the search space exponentially, while adding one character type only multiplies it dozens of times. That is why long passwords beat short clever ones.

Generation is only half the story: a random password not saved in a password manager is forgotten within a day, pushing you back to weak reuse. Use Bitwarden, 1Password or KeePass and let them remember your randomness.

Also use the generator for fake security answers and planted answers — any text that must be unguessable is a candidate for this kind of tool.

FAQ

Is the generated password sent anywhere?

No — generation is fully local in your browser via a cryptographic generator, with zero transmission anywhere.

How long should it be?

16 characters is a good minimum, and 20+ for critical accounts like your main email and password manager.

Why not use a passphrase instead?

An excellent option too — a 4-5 word random, unrelated passphrase matches a long random password and is easier to remember.
