تحويل HTML إلى Markdown

حوّل العناوين والفقرات والروابط والقوائم والجداول من HTML إلى Markdown محلياً.

🔒 تُعالج الملفات محلياً في المتصفح عندما تدعم الأداة ذلك dev

حوّل العناوين والفقرات والروابط والقوائم والجداول من HTML إلى Markdown محلياً.

طريقة الاستخدام

  1. الصق مقتطف HTML أو الشيفرة التي تريد نقلها إلى محرر Markdown.
  2. حوّل النص وراجع بنية العناوين والقوائم والجداول والروابط.
  3. انسخ الناتج وعدّل التنسيق أو الروابط يدوياً إذا كان HTML الأصلي يستخدم تخطيطاً معقداً.

شرح مفصّل

يحوّل المحول العناصر الشائعة إلى صياغات Markdown: العناوين والفقرات والتأكيد والاقتباسات والقوائم والجداول وفواصل الأسطر. لا يستطيع Markdown تمثيل كل تفاصيل CSS أو التخطيطات المخصصة، لذلك قد تختلف النتيجة بصرياً عن الصفحة الأصلية.

تُحلل الشيفرة داخل DOM غير نشط في المتصفح ولا تُنفّذ عناصر script. لا تُعرض النتيجة كـ HTML؛ بل كنص داخل حقل، وتُستبعد روابط مثل javascript: ولا تتحول إلى روابط قابلة للنقر.

تقتصر المدخلات على 1 MiB. راجع الروابط المطلقة وبيانات الصور قبل نشر Markdown، خصوصاً إذا كان المحتوى سينتقل إلى مستودع أو نظام عام.

أسئلة شائعة

هل يحول المحول تصميم CSS إلى Markdown؟

لا. Markdown يصف المحتوى والبنية الأساسية ولا يمثل معظم التخطيطات أو الأنماط. قد تحتاج إلى تحرير الناتج يدوياً.

هل تُنفّذ الشيفرات الموجودة في HTML؟

لا. يُحلل المحتوى في DOM غير نشط، وتُتجاهل عناصر script وstyle ومحتوى التضمين النشط.
