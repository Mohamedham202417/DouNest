تحويل صورة إلى Base64

🔒 تُعالج الملفات محلياً في المتصفح عندما تدعم الأداة ذلك media

حوّل صورة إلى نص Base64 أو Data URL داخل المتصفح. حد الملف 8 ميغابايت.

طريقة الاستخدام

  1. اختر صورة من جهازك بصيغة شائعة مثل PNG أو JPEG أو WebP.
  2. اختر إخراج Base64 خاماً إذا كانت وجهتك تتوقع بايتات مرمّزة، أو Data URL إذا كانت تحتاج بادئة data:image/...;base64.
  3. اضغط التحويل، ثم انسخ النص الناتج واختبره في التطبيق أو الصفحة التي ستستخدمه فيها.

شرح مفصّل

Base64 طريقة لتمثيل البيانات الثنائية بأحرف نصية. لا تحوّل صيغة الصورة نفسها ولا تضغطها؛ بل ينتج عنها نص أطول من الملف الأصلي، ولذلك قد لا تكون مناسبة للصور الكبيرة أو صفحات الويب التي تحتوي على صور كثيرة.

استخدم Base64 الخام مع واجهة برمجية تتوقع سلسلة مرمّزة فقط. واستخدم Data URL عند تضمين الصورة في HTML أو CSS أو موضع يقبل عنوان بيانات كاملاً. يتضمن Data URL نوع MIME الذي يقدمه المتصفح.

تقرأ الأداة الملف محلياً بواجهة File API ولا ترفعه إلى DouNest. حد 8 MiB مقصود لتقليل ضغط الذاكرة، لكن قد يستهلك النص الناتج مساحة كبيرة عند نسخه أو تضمينه. لا تضع بيانات خاصة في وجهة عامة.

أسئلة شائعة

هل Base64 يقلل حجم الصورة؟

لا. الترميز ليس ضغطاً، وغالباً يكون النص أكبر من الملف الثنائي. استخدم أداة ضغط صور إذا كان هدفك تقليل الحجم.

ما الفرق بين Base64 وData URL؟

Base64 هو النص المرمّز وحده؛ أما Data URL فيضيف بادئة تتضمن نوع المحتوى مثل data:image/png;base64,.
