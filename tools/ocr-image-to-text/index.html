استخرج النص من الصور والمستندات الممسوحة — عربي وإنجليزي.

طريقة الاستخدام

  1. اسحب صورة تحتوي نصاً (ممسوحة أو فوتوغرافية) إلى منطقة الرفع.
  2. انتظر تحميل محرك التعرف ولحظات التحليل الأول.
  3. شاهد النص المستخرج يظهر تدريجياً في لوحة النتيجة.
  4. راجع النص وصحح الأخطاء البسيطة إن وُجدت.
  5. انسخ النص أو نزّله ملف TXT جاهزاً.

شرح مفصّل

التعرف الضوئي على الحروف OCR هو جسر بين عالم الورق والصور وعالم النص القابل للمعالجة: فاتورة مطبوعة، لقطة شاشة قديمة، صفحة كتاب ممسوحة — كلها نص ميت بلا OCR، وحية قابلة للبحث والتحرير بعده.

الأداة تعمل بمحرك Tesseract.js مفتوح المصدر — سليل مشروع Tesseract الذي طورته HP ثم كرّسته Google وأصبح المعيار المفتوح عالمياً — يعمل داخل متصفحك بالكامل دون رفع أي صورة.

أول تشغيل ينزّل ملفات اللغة (بضع ميغابايتات) ويخزنها محلياً — التشغيلات التالية أسرع بكثير، وهذا سلوك تقنية ويب حديث طبيعي.

دقة النتيجة تتبع جودة الصورة بقوة: 300 DPI للمسوح، إضاءة متساوية للفوتوغرافات، وزاوية مستقيمة — النص العربي مطبعي يعطي نتائج جيدة، أما المخطوط فما زال تحدياً لكل محركات OCR العالمية.

الدمج الذكي: صورة فاتورة → OCR → بيانات إلى JSON عبر محول CSV — سلسلة أدوات DouNest تحول الورق إلى بيانات منظمة كاملة دون أن يغادر أي ملف جهازك.

أسئلة شائعة

هل يدعم اللغة العربية؟

نعم — اختر العربية من قائمة اللغات؛ النص المطبوع يعطي نتائج جيدة والمخطوط أضعف.

لماذا أول عملية بطيئة؟

ينزّل محرك التعرف وملفات اللغة مرة واحدة ثم تخزن محلياً — التالي أسرع بكثير.

هل صوري ترفع لأي مكان؟

لا — كل المعالجة داخل متصفحك، والصورة لا تغادر جهازك أبداً.
