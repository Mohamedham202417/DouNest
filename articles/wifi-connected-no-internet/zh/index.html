Wi-Fi 已连接却无法上网？Windows、iPhone 和 Android 免费排查指南

作者 DouNest· 发布于: 2026-10-15

Wi-Fi 旁显示“已连接”并不代表互联网一定可用。先换一个设备、打开另一个网站，再判断问题来自单个设备、路由器还是运营商。先尝试可撤销的步骤，因为网络重置可能清除已保存的设置。

要点

  • 如果所有设备都无法上网，先检查路由器、调制解调器和运营商，不要先改某一台手机或电脑。
  • 如果只有一台设备出问题，重新连接网络并使用设备自带的诊断工具。
  • 简单检查未完成前，不要按路由器的恢复出厂设置按钮，也不要重置网络。

先找出问题来自哪里

打开另一个网站和应用，再用另一部手机、平板或电脑测试同一 Wi-Fi。如果只有一个网站打不开，网络可能正常。如果同一 Wi-Fi 下所有设备都无法上网，问题更可能在路由器、调制解调器或运营商连接。如果其他设备正常，就重点检查故障设备。PCMag 的网络故障排查指南也建议先这样区分。

先尝试这些低风险方法

  1. 检查 Wi-Fi 和飞行模式。 确认 Wi-Fi 已开启、飞行模式已关闭。靠近路由器，并查看互联网/状态指示灯。
  2. 检查运营商是否停机。 使用移动数据或另一网络上的设备查看运营商服务状态页。大范围故障无法靠修改单台设备设置解决。
  3. 重启调制解调器和路由器。 如果所有设备都受影响，将两者断电约 30 秒。先接通调制解调器，等指示灯稳定后再接通路由器并等待启动。使用电源插头，不要按可能清除配置的小型恢复出厂设置按钮。Microsoft 在其 Wi-Fi 排障指南中说明了这一顺序。
  4. 重新连接故障设备。 关闭再打开 Wi-Fi，重新选择已知网络。仍不行时，选择“忘记网络”，再输入正确密码连接。只有确认知道密码时才这样做；不同设备菜单名称不同。
  5. 暂时检查 VPN 或安全过滤。 如果使用 VPN 或安全应用，可通过应用自身控制短暂断开后再测试。不要卸载工作/学校管理软件，也不要让保护长期关闭；如果只有关闭后才能连接，请联系管理员或服务提供方。

按设备排查

Windows 11 或 Windows 10

Windows 11 可在 Get Help 应用中运行“网络和 Internet”疑难解答；并在“设置 → 网络和 Internet”检查 Wi-Fi 状态及飞行模式。Microsoft 也建议忘记网络后重新加入。问题仍在时，通过 Windows 更新或电脑厂商更新 Wi-Fi 驱动。网络重置只作为最后手段：它会重新安装网络适配器，VPN 或虚拟网络软件可能需要重新配置。

iPhone 或 iPad

打开“设置 → Wi-Fi”，确认 Wi-Fi 已开启，目标网络旁有蓝色勾号，并关闭飞行模式。如果其他设备也无法连接，检查并重启路由器；如果只有 iPhone 出问题，尽可能测试另一个 Wi-Fi。Apple 提醒，“还原网络设置”会删除已保存的 Wi-Fi 网络和密码，以及蜂窝网络、VPN/APN 设置。先尝试简单方法；受组织管理的设备应先咨询 IT。请参阅 Apple 官方说明。

Android 手机或平板

重启设备，然后对比 Wi-Fi 和移动数据：关闭 Wi-Fi、开启移动数据测试，再反向测试。如果移动数据正常而 Wi-Fi 不行，重新连接保存的网络或试另一个 Wi-Fi。菜单名称因厂商和系统版本而异。Google 的 Android 官方排障步骤介绍了这种对比方法。

何时联系运营商

如果重启调制解调器和路由器后，多台设备仍无法打开多个网站，请查看运营商故障页面或联系客服。说明路由器互联网指示灯状态；若能测试，也告知有线连接是否正常。若只有工作或学校设备出问题，修改受管理的网络设置前先联系管理员。

常见问题

为什么 Wi-Fi 已连接但没有互联网？

设备可能连上了路由器，但路由器失去了通往运营商的连接。VPN、保存的网络配置或运营商故障也可能导致此情况。先用另一台设备缩小范围。

应该更改 DNS 设置吗？

不应作为第一步。错误或不必要的 DNS 更改可能带来新问题。只有诊断指向 DNS 时，才遵循运营商或设备厂商的书面说明。

重置网络会删除文件吗？

通常不会删除照片或文档，但可能清除已保存的 Wi-Fi 密码以及网络、VPN 或蜂窝设置。确认前请阅读设备屏幕上的警告。

应该将路由器恢复出厂设置吗？

普通“已连接但无互联网”提示不需要这样做。恢复出厂设置可能清除 Wi-Fi 名称、密码和运营商配置。先断电重启，恢复出厂设置前咨询运营商或厂商。
