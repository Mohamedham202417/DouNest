# تقرير استراتيجية المحتوى وSEO — DouNest

**تاريخ التقرير:** 15 أكتوبر 2026  
**نطاق التحليل:** مستودع DouNest المحلي بعد إصدار v4، دون بيانات Google Search Console أو GA4 أو Ahrefs/Semrush.

## الملخص التنفيذي

يمتلك DouNest أساساً جيداً للنمو العضوي: 44 أداة قابلة للفهرسة، صفحات هبوط ثابتة، مركز PDF، مركز تحويل، و8 مقالات ثنائية اللغة. الفجوة الأهم ليست نقص الصفحات التقنية، بل نقص المحتوى الذي يلتقط نية البحث قبل استخدام الأداة مباشرة؛ لذلك أضيفت أربع مقالات جديدة حول Excel إلى JSON، وPDF إلى Word، والصور إلى PDF، والتحويل بين CSV وJSON. هذه المقالات مرتبطة بأدوات فعلية وتجيب عن أسئلة القرار الشائعة: أي صيغة أختار؟ كيف أحافظ على الجودة؟ ماذا يحدث للخصوصية؟ لا تتوفر في هذه المراجعة أرقام الظهور أو النقرات أو الترتيب، لذلك لا يجوز اعتبار الأولويات توقعاً لحجم البحث أو وعداً بالترتيب. يجب استخدام هذا التقرير كخطة تحريرية قابلة للقياس، ثم ربطها بتصدير Search Console بعد 28 يوماً. الأولوية الحالية هي بناء عناقيد حول التحويل والخصوصية والبيانات، تقوية الروابط من المقالات إلى الأدوات ومن مراكز الأدوات إلى المقالات، ثم مراقبة الفهرسة والنقرات لكل صفحة جديدة.

## 1. لقطة التغطية الحالية

| الأصل | الوضع الحالي | القراءة SEO |
|---|---:|---|
| الأدوات | 44 أداة | تغطية قوية لنية الاستخدام المباشر/التحويل |
| المقالات قبل التحديث | 8 | تغطية جيدة للخصوصية، JSON، الصور، AI، الملفات وكلمات المرور |
| المقالات المضافة | 4 | تغطية نية التحويل والبيانات المرتبطة بالأداة |
| إجمالي المقالات بعد التحديث | 12 | بداية عنقود تحريري قابل للتوسع |
| صفحات المقالات الثابتة | مولّدة عبر `build.mjs` | قابلة للفهرسة دون اعتماد على JavaScript للقراءة الأولى |
| Sitemap | يُعاد توليده آلياً | يجب إرسال النسخة الجديدة في Search Console |

**ملاحظة البيانات:** لا يحتوي المستودع على بيانات النقرات أو الترتيب أو الروابط الخلفية. لذلك تم الاعتماد على جرد الموقع وملاءمة نية البحث للأدوات، وليس على حجم بحث مخمّن.

## 2. فجوات المحتوى ذات الأولوية

| الأولوية | عنقود البحث | نية المستخدم | صفحة الاستهداف | الإجراء المنفذ |
|---:|---|---|---|---|
| 1 | Excel إلى JSON / spreadsheet to JSON | تعليمية + استخدام مباشر | `/articles/excel-to-json-guide/` و`/tools/excel-to-json/` | مقال ثنائي اللغة مع خطوات وتنظيف البيانات وروابط داخلية |
| 2 | PDF إلى Word / تحويل PDF قابل للتحرير | تعليمية + تحويل | `/articles/pdf-to-word-guide/` و`/tools/pdf-to-word/` | مقال يفرّق بين PDF النصي والممسوح وOCR |
| 3 | صور إلى PDF / image to PDF | تعليمية + تحويل | `/articles/image-to-pdf-guide/` و`/tools/image-to-pdf/` | مقال عن المقاس والاتجاه والجودة والضغط |
| 4 | CSV إلى JSON والعكس | تعليمية + مطورين | `/articles/csv-json-conversion-guide/` و`/tools/csv-to-json/` | مقال عن UTF-8 والفواصل والحقول الفارغة |
| 5 | أمان الملفات محلياً | توعوية + ثقة | المقالات الحالية + صفحات الأدوات | توسيع الأسئلة الشائعة وإظهار رسالة المعالجة المحلية |
| 6 | صفحات مقارنة الصيغ | قرار/مقارنة | مراكز `/pdf/` و`/convert/` | المرحلة التالية: صفحات «متى تستخدم X بدل Y؟» |

## 3. ما تم تحسينه تحريرياً

- **إجابة مباشرة في المقدمة:** كل مقال يبدأ بتعريف المشكلة والفرق بين الحالات، بدلاً من مقدمة عامة.
- **مطابقة نية الأداة:** كل مقال يربط القارئ بأداة واحدة أساسية وأدوات مساعدة مرتبطة.
- **معلومات كافية لاتخاذ القرار:** تم تضمين الجودة، الخصوصية، القيود، والتحقق بعد التحويل.
- **عناوين قابلة للتوسّع:** العناوين تستهدف صيغة المشكلة + الإجراء، وتحتوي على المصطلح العربي والإنجليزي حيث يفيد ذلك.
- **تنويع نية البحث:** المحتوى الجديد يغطي التعلم، المقارنة، الاستخدام، واستكشاف الأخطاء.

## 4. خريطة الربط الداخلي

```text
المقالات/
├── excel-to-json-guide ──> Excel إلى JSON ──> JSON Formatter ──> Excel إلى CSV / CSV إلى JSON
├── pdf-to-word-guide ────> PDF إلى Word ────> OCR من صورة إلى نص ──> PDF إلى TXT
├── image-to-pdf-guide ───> صورة إلى PDF ────> ضغط PDF ──> ضغط الصور
└── csv-json-conversion ──> CSV إلى JSON ────> JSON Formatter ──> JSON إلى CSV
```

تمت إضافة روابط عكسية من صفحات الأدوات الخمس ذات الصلة إلى المقالات الجديدة، خصوصاً لأدوات Excel وPDF والصور وCSV/JSON، حتى لا تبقى المقالات صفحات طرفية في بنية الموقع.

## 5. متطلبات القياس

بعد النشر، أنشئ مجموعة متابعة في Search Console لكل صفحة جديدة وسجّلها أسبوعياً:

| المؤشر | لماذا يهم | إشارة النجاح الأولية |
|---|---|---|
| الفهرسة | هل وصلت الصفحة إلى Google؟ | ظهور الصفحة في فحص URL وsitemap |
| مرات الظهور | هل تطابق الصفحة استعلامات بحث؟ | نمو أسبوعي بعد اكتمال الفهرسة |
| CTR | هل العنوان والوصف مقنعان؟ | تحسن بعد اختبار العنوان دون تغيير المحتوى كله |
| متوسط الموضع | هل نقترب من الصفحة الأولى؟ | تحسن تدريجي للكلمات غير البراندية |
| نقرات إلى الأداة | هل المحتوى يحقق هدف الموقع؟ | نقرات من المقالة إلى أداة التحويل |
| التحويل/الاستخدام | هل الزائر شغّل الأداة؟ | قياس حدث استخدام الأداة في GA4 عند تفعيله |

لا توجد حالياً بيانات كافية لإنتاج رسوم حقيقية للزيارات أو الدول أو الكلمات. يجب عدم إنشاء رسوم تقديرية قبل توفير تصدير GSC/GA4.

## 6. خطة التوسع التالية

1. **تحديث المقالات الحالية:** إضافة رابط أداة أساسي ورابطين سياقيين لكل مقال من المقالات الثمانية القديمة.
2. **إنشاء صفحات المقارنة:** `PDF إلى Word أم PDF إلى TXT؟`، و`CSV أم JSON؟`، و`ضغط الصورة قبل PDF أم بعده؟`.
3. **توسيع الأسئلة الشائعة:** إضافة سؤالين إلى أربعة أسئلة فريدة لكل عنقود، مع إجابة قصيرة قابلة للاقتباس.
4. **تقوية صفحات المراكز:** إضافة قسم «دليل مختصر» في `/pdf/` و`/convert/` يربط بالمقالات الجديدة.
5. **التحقق بعد 28 يوماً:** استخراج Queries وPages من GSC، ثم إعادة ترتيب الأولويات بناءً على الظهور والموضع، لا على التخمين.
6. **تحديث التاريخ فقط عند وجود قيمة جديدة:** لا تغيّر تاريخ المقال لمجرد التحديث الشكلي؛ أضف أمثلة أو أخطاء أو بيانات جديدة موثقة.

## 7. قائمة الأولويات التنفيذية

1. إرسال `sitemap.xml` الجديد إلى Google Search Console وفحص URLs للمقالات الأربع.
2. التحقق من ظهور الروابط العكسية الجديدة في الزحف القادم ومراقبة نقراتها.
3. تفعيل قياس نقرات المقالات إلى الأدوات عند توفر GA4.
4. جمع أول تصدير GSC بعد 28 يوماً وتقسيم الكلمات إلى: تحويل، PDF، بيانات، خصوصية.
5. بناء صفحتي مقارنة فقط بعد ظهور طلب بحث فعلي أو استعلامات قريبة في GSC.

## حدود التقرير

هذا تقرير تحريري مبني على بنية الموقع والملفات المتاحة فقط. لا يتضمن أحجام بحث، مراكز فعلية، CTR، بيانات دول، Core Web Vitals، أو تحليل روابط خلفية. أي قرار تجاري أو توقع زيارات يحتاج إلى بيانات Search Console وAnalytics وأداة كلمات مفتاحية.
