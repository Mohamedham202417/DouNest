Security & Privacy — Local Password and TOTP Tools

Generate passwords, check strength, and use TOTP without sending secrets to a server.

Open the page in your browser to use the interactive workspace.

Generate a random password in the browser, get a rough strength estimate, or calculate a TOTP code from a secret. Treat passwords and authenticator seeds as sensitive even when processing is local.

Use security tools carefully

  1. For a password, choose a length and character sets, then save it in a trusted password manager.
  2. For a strength estimate, use a test password if you are on a device you do not control.
  3. For TOTP, enter the seed from its issuer, match the account's period and digits, and never share the code or seed.

What these tools do

The password generator uses the browser's cryptographic random source. The strength checker is a rough educational estimate, not a penetration test or guarantee. TOTP derives a changing code from a secret and time; its settings must match the issuer.

Protect authentication secrets

Values are not sent to a DouNest server, but avoid shared devices and screen recording when entering secrets. Do not replace your primary authenticator workflow unless you understand how the seed and recovery process are managed.

Privacy

Processing happens in the browser; some tools may load public libraries when needed. The hub does not store your password or TOTP secret on a server. Clear the input and close the tab on shared devices.

Frequently asked questions

Is the password generator secure?

It uses the browser's cryptographic random source, but security also depends on length, saving it in a trusted manager, and device security.

Is the password-strength score exact?

It is a rough educational estimate, not a guarantee against attacks. Use a unique long password, a trusted manager, and multifactor authentication.

Is my TOTP secret uploaded?

It is not sent to a DouNest server. Do not enter it on an untrusted device or session, and match the issuer's period and digit settings.

Does SHA-256 encrypt data?

No. A hash is one-way, not reversible encryption, and a fast hash alone is not suitable for password storage.
