منسّق JSON

تنسيق، تصغير، والتحقق من صحة JSON.

🔒 تُعالج الملفات محلياً في المتصفح عندما تدعم الأداة ذلك dev

تنسيق، تصغير، والتحقق من صحة JSON.

طريقة الاستخدام

  1. الصق نص JSON في مربع المدخل، أو اسحب ملف .json إلى الصفحة مباشرة.
  2. اضغط زر التنسيق ليصبح النص مُسنداً بمسافات واضحة مقروءة.
  3. أو اضغط تصغير لإزالة كل المسافات وتجهيز الملف للنشر في الإنتاج.
  4. إن وُجد خطأ سيُبرز موقعه برقم السطر بدقة لتصلحه فوراً.
  5. انسخ النتيجة إلى الحافظة أو نزّلها ملفاً جاهزاً.
  6. كرر العملية مع أي عدد من الملفات — كل شيء يُعالج محلياً.

شرح مفصّل

JSON هو لغة تبادل البيانات المشتركة بين كل الأنظمة الحديثة تقريباً، لكن الملفات القادمة من الخوادم تصل عادة في سطر واحد مضغوط يستحيل قراءته بالعين. منسق JSON يحول هذا الكتلة الصماء إلى شجرة واضحة الأسطر والمستويات، فيصبح فهم بنية البيانات وتحريرها ممكناً في ثوانٍ.

القيمة الأكبر تظهر عند تصحيح الأخطاء: الفاصلة الزائدة بعد آخر عنصر، وعلامات الاقتباس المفردة، والمفاتيح غير المقتبسة — كلها أخطاء شائعة يكتشفها المدقق ويحدد سطرها بدقة، بدلاً من رسالة Parser error غامضة في وحدة التحكم.

وضع التصغير له استخدام معاكس تماماً: قبل نشر ملف إعدادات أو إرساله عبر الشبكة، تقليل الحجم بإزالة المسافات يوفر نطاقاً ترددياً حقيقياً في الملفات الكبيرة المتكررة.

خصوصية البيانات مصممة في الأداة من الأساس: التحليل والتنسيق يحدثان داخل متصفحك بكود جافاسكربت محلي، فلا يغادر ملفك جهازك إطلاقاً — وهذا مهم جداً عند التعامل مع إعدادات تحتوي مفاتيح أو بيانات عملاء.

سواء كنت تتفقد استجابة API، أو تجهز ملف ترجمة، أو تحرر إعدادات تطبيق، فإن دورة لصق-تنسيق-تحقق-نسخ هنا تغطيها دون تسجيل ودون حدود استخدام.

أسئلة شائعة

هل تُرفع بياناتي إلى خادم؟

لا. الأداة تعمل بالكامل داخل متصفحك، والنص لا يغادر جهازك إطلاقاً حتى لو كان يحتوي مفاتيح سرية.

ما الحد الأقصى لحجم الملف؟

لا يوجد حد مفروض من الخادم لأن لا خادم؛ الحد الوحيد هو ذاكرة متصفحك، وملفات بمئات الكيلوبايتات تُعالج فوراً.

هل يدعم JSON5 أو التعليقات؟

المدقق يتبع معيار JSON الرسمي الصارم، لذا التعليقات غير مدعومة — استخدم أداة التحقق بعد إزالتها من الملف.
