How to use the conversion hub

  1. Add one file; the hub lists conversions supported for its detected extension.
  2. Choose a direction and adjust quality or other settings when available.
  3. Download the output and open it in the target app to verify text, layout, and values before replacing the source.

Supported conversion paths

Available paths include PNG/JPG/WebP image conversion, PDF text extraction or page-image export, CSV ↔ JSON, XLSX to CSV or JSON, DOCX to text, TXT to PDF, SVG to PNG, and JSON ↔ YAML.

What may change?

PDF to Word extracts text into an HTML-based .doc file and does not preserve page layout. XLSX reading is simplified and may omit worksheets, formulas, or formatting; generated text PDFs render Latin characters best. Review converted output before relying on it.

Processing and privacy

Core conversions run in your browser; selected files are not sent to a DouNest server. Some conversion libraries load on demand from a content-delivery network, so those paths need network access.

Frequently asked questions

Does PDF-to-Word preserve the original layout?

No. The current path extracts text into an HTML-based .doc file; columns, images, and layout may not be preserved. Review and edit the document before relying on it.

Can it OCR a scanned PDF?

No. PDF-to-TXT reads an existing text layer. Image-only pages need a separate OCR tool.

Does Excel conversion preserve formulas?

The current paths move cell data into CSV or JSON in a simplified way and do not guarantee formulas, formatting, or every worksheet.

Are files uploaded to a server?

Selected files are processed in your browser and are not sent to a DouNest server; some processing libraries are loaded from a content-delivery network when needed.

Why is my desired output format missing?

The hub lists only conversions supported for the detected source type. Open a related format-specific tool or choose a supported source file.
