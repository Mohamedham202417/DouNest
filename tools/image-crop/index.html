Image Cropper

Crop images to common aspect ratios or custom dimensions.

🔒 Files are processed locally when the tool supports it media

Crop images to common aspect ratios or custom dimensions.

How to use

  1. Choose one or more images.
  2. Select an aspect ratio. The crop is centered automatically; choose Free to set width and coordinates.
  3. Choose an output format, then run and save.

Detailed explanation

Cropping uses Canvas in your browser; the image is not uploaded.

Presets cover square, social portrait and widescreen formats.

JPG output uses a white background because JPEG has no transparency.

FAQ

Is there a live preview?

This version applies the crop when you run it; it does not show a pre-download preview.
