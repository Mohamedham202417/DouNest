How to use

  1. Type the text or URL you want to turn into a QR code.
  2. Set size and error-correction level (L/M/Q/H) for your use case.
  3. Press Generate and the code appears instantly in high resolution.
  4. Download the code as PNG or copy it directly.
  5. Test the final code with your phone camera before printing.

Detailed explanation

A QR code stores binary data in a scan pattern designed for extreme speed, originally created to track car parts in Japan before conquering the world's menus, payments, tickets and Wi-Fi sharing.

The error-correction level is the most important technical decision: level H keeps the code scannable even if 30% is covered by a stamp or logo — that is why restaurant logos sit confidently on codes, while level L fits more data but shreds easily.

The golden rule of printing: at least 2×2 cm for close-range scans, growing with camera distance — a billboard QR needs square meters.

Content determines phone behavior after scanning: a URL opens the browser, wifi: auto-connects to the network, mailto: opens email — the tool supports all these patterns through free text.

Generation is fully local via the qrcode library in your browser, so private links and network credentials never reach anyone — vital when codes carry sensitive info.

FAQ

Does the generated code work forever?

Yes — the code is static and depends on no service; it works as long as its content stays valid (e.g. the link is alive).

What is the maximum data size?

About 3000 text characters or 700 digits — but short codes scan faster and more reliably.

Why does my printed code fail to scan?

Usually too small, low contrast, or print distortion — enlarge and print on pure white.
