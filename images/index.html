How to use the image hub

  1. Add one image or a batch in a format supported by the chosen operation; review the listed files and sizes.
  2. Choose output format, quality, or width. For batch work, check the image order before creating a PDF.
  3. Run the operation and inspect dimensions, transparency, colors, and metadata in the exported files.

Convert and compress images

Supported images can be converted to WebP or JPG, resized, or exported to PDF. Re-encoding can change colors or transparency: JPG does not preserve transparency, while PNG is often suitable for transparent graphics.

Crop, orientation, and metadata

Tools crop to common aspect ratios, rotate or flip, read selected EXIF tags from JPEG, or re-encode to remove much of the metadata. Strip location data before sharing when privacy matters, then inspect the output rather than assuming every format carries identical metadata.

Background removal and privacy

Background removal downloads a processing model on first use and can take time or memory, especially for large images. The selected image is not sent to a DouNest server; model files or processing libraries may be downloaded from an external content-delivery network.

Frequently asked questions

Which image format is best for web compression?

It depends on the image and compatibility needs. Compare WebP or JPG for photographs; use PNG when transparency or crisp graphic edges matter.

Does JPG keep transparency?

No. Transparent areas are filled with white when exported as JPG. Choose PNG or WebP if you need transparency.

Are my photos uploaded for background removal?

The selected image is not sent to a DouNest server. The browser may download model files from a content-delivery network on first use.

Does stripping EXIF remove photo location?

Re-encoding removes much of the metadata in supported outputs, but inspect the exported file with an EXIF reader before publication if location removal is essential.

Why won't my HEIC or AVIF image open?

Decoder support varies by browser and operating system. Try the dedicated HEIC tool or convert locally to a supported format first.
