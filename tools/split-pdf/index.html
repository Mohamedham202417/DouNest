Split PDF

Extract pages or ranges from a PDF into separate files.

🔒 Files are processed locally when the tool supports it media

Extract pages or ranges from a PDF into separate files.

How to use

  1. Drag a PDF into the drop zone.
  2. Choose split mode: each page as a file, or custom ranges (1-3, 5, 8-10).
  3. Review the page preview to confirm cut points.
  4. Press Split and wait for local file generation.
  5. Download results — as separate files or one ZIP containing everything.

Detailed explanation

Splitting is the complement of merging: a huge contract where you need only its appendices, a book to separate into chapters, a report to distribute among different team sections — all end as «give me pages 5-12 alone».

«Each page as a file» mode is perfect for systems requiring single-page uploads (one ID document per field), while custom ranges serve smart selective extraction — the tool supports both with flexible range syntax.

pdf-lib copies requested pages into new documents with bit-perfect fidelity: text, images, links and quality are preserved literally — no regeneration, no degradation, watermarks and rights stay intact.

The smartest use case: extract specific pages then merge them with another file's pages — a compound workflow completed via merge-PDF right after splitting, on the same site.

Privacy is absolute as always: legal and medical documents split in your browser's memory — no server sees a single page.

FAQ

How do I write ranges?

Comma-separated: 1-3, 5, 8-10 — ranges are inclusive and numbers follow actual page numbering.

Is the original file kept intact?

Yes — the original is never touched; splitting only generates new copies.

Can I split a password-protected file?

Open-password-only files may work; fully encrypted ones need unlocking first.
